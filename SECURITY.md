# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 1.x | yes |

## Reporting a vulnerability

Please **do not** open a public issue. Use GitHub's private vulnerability reporting instead
(**Security → Report a vulnerability** on the repository page). You will get an
acknowledgement within 7 days.

The package has no runtime dependencies and makes no network calls. It reads only the plan
and rules files you pass to it.
